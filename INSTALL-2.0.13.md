# BillNgai 2.0.13 direct-download update

The signed/notarized universal Mac installer and unsigned Windows x64 Beta
are the desktop clay update. App colors, seller document branding, frozen
snapshots and the 2.0.12 financial/sync runtime remain intact.

Download the matching platform from https://billiong-landing.pages.dev.
Mac requires macOS 12+. Windows 11 x64 is tested; Windows remains unsigned Beta.
Back up JSON and evidence attachments separately, retain existing PDFs, quit
normally, and use the normal installer/update procedure. Do not reset/import
or reconnect an already connected 2.0.12 profile merely to apply this update.
Updates are manual downloads; no in-app updater is included.

This release was tested with isolated synthetic profiles. Owner's installed
Mac/PC application and billing profile were not replaced or changed by release QA.
Previous 2.0.12 artifacts remain for rollback. For a failed update, preserve the
current profile and use the previous installer; 2.0.13 uses the same data format.
Read RELEASE-2.0.13.md and WINDOWS-2.0.13.md for verification and known limitations.
The separate Mac Store and mobile versions require their own release gates.
