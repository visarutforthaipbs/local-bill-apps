# Direct Pro → App Store offer: private customer message draft

Do not send until both store builds are live, BillNgai Pro IAP is approved, the free offer code is active, and the buyer is verified in the private BillNgai Sales Log. Insert the actual redemption URL only in a private customer message; never commit it. This draft is for the direct Pro buyer, not for App Store listing text.

> ลิงก์แลก Pro ฟรีของคุณ: [ลิงก์แลกโค้ดข้อเสนอจาก App Store Connect] (ใช้ได้ 1 ครั้ง ภายใน [วันหมดอายุ/ไม่มีวันหมดอายุ])
>
> ก่อนย้ายข้อมูล ให้อัปเดตบิลง่ายเวอร์ชันดาวน์โหลดตรงบน Mac เป็น 2.0.15 แล้วเปิด ตั้งค่า → ข้อมูลและสำรอง → ย้ายไป App Store → ส่งออกไฟล์สำหรับย้าย… เก็บไฟล์ไว้ในที่ที่เครื่องใหม่เปิดได้

> ติดตั้งบิลง่ายจาก App Store แล้วเปิดลิงก์ด้านบนด้วย Apple Account ที่จะใช้กับแอป เปิดแอปครั้งแรกแล้วเลือก นำเข้าจากเวอร์ชันเดิม… หากผ่านหน้าเริ่มต้นไปแล้ว ใช้ปุ่มนำเข้าใน ตั้งค่า → ข้อมูลและสำรอง แทน หลังนำเข้าให้ตรวจจำนวนเอกสาร เลขเอกสารล่าสุด และยอดสำคัญกับเครื่องเดิม จากนั้นกด ตั้งค่า → กู้คืนการซื้อ หาก Pro ยังไม่แสดง
>
> รหัส Pro เดิมยังใช้กับ DMG รุ่นสุดท้ายได้ระหว่างย้าย หากติดปัญหา ตอบข้อความนี้ได้เลยครับ

Before sending, test redemption with a sandbox offer code (never consume the customer code) and confirm the customer has not already purchased App Store Pro. Log recipient, custom code, creation and send date, redemption status, and expiry in the private sales log. Use one code with a redemption limit of one per buyer.
