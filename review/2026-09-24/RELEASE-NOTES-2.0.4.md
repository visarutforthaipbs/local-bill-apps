# BillNgai 2.0.4 — Mac Direct

แก้ปุ่ม “ยกเลิกและเก็บเอกสาร” และการบันทึกรับชำระ เปิดอ่านข้อมูลเอกสารเดิมที่เก็บไว้ได้โดยไม่ต้องยกเลิกเอกสาร

- แยกเก็บเข้าคลังออกจากการยกเลิกพร้อมเหตุผล ไม่ลบต้นฉบับเพื่อแก้ปัญหาการแสดงผล
- เอกสารเดิมที่ไม่มีสำเนาข้อมูล ณ วันออก แสดงข้อมูลที่เก็บไว้และส่วนที่ไม่ทราบ ไม่สร้างสำเนาออกเอกสารย้อนหลังเพื่อพิมพ์หรือแชร์
- ใบแจ้งหนี้เดิมที่เข้าเงื่อนไขสามารถแนบหลักฐานและทบทวนการรับเงินแยกจากต้นฉบับ รองรับเฉพาะรับเต็มจำนวนเป็นเงินบาทและสถานะไม่จด VAT จากนั้นเลือกออกใบเสร็จธรรมดาใหม่ด้วยวันที่ออกวันนี้ ไม่แก้เอกสารเดิม
- แก้การบันทึกเมื่อปิดหน้าต่าง รายงานนับซ้ำ การบันทึกข้อมูลลูกค้า/ตั้งค่า และรายการประจำ พร้อมตรวจข้อมูลนำเข้าก่อนแทนที่ข้อมูลเดิม

## ก่อนอัปเดต

สำรองฐานข้อมูลและเก็บ PDF ต้นฉบับก่อน ปิด BillNgai แล้วแทนที่แอปใน Applications
หากใช้หลักฐานแนบใน 2.0.4 ให้เก็บทั้งฐานข้อมูล JSON และชุดไฟล์หลักฐานแยกกันนอกดิสก์เดิม
JSON ไม่มีไฟล์แนบอยู่ข้างใน อย่าลบข้อมูลเดิมเมื่อเกิดข้อผิดพลาด

## ข้อจำกัดยังคงอยู่

ไม่รองรับใบกำกับภาษี ใบเสร็จผู้จด VAT เงินต่างประเทศ รับบางส่วน มัดจำ หรือคืนเงิน
ต้องตรวจภาษีหัก ณ ที่จ่ายตามธุรกรรม ไม่ใช้อัตรา 3% อัตโนมัติ พักประมาณการภาษีที่ต้องจ่าย/ขอคืน
ซิงก์และกู้คืนคลาวด์ และ e-Tax รวมถึง Pro การตรวจซอฟต์แวร์และแฮชหลักฐานไม่ใช่การรับรอง
ธุรกรรมหรือการรับรองทางบัญชี/กฎหมาย ตรวจกรณีจริงกับผู้เชี่ยวชาญ

Mac Direct เท่านั้น: macOS 12+; Universal Intel/Apple Silicon (ทดสอบจริงบน Apple Silicon)
Windows ยังเป็น 2.0.1 Beta และ Mac App Store ยังรออัปเดต ไม่อ้างว่าช่องทางอื่นมีมาตรการเดียวกัน
