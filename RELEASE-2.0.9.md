# BillNgai 2.0.9 — private macOS release

Released locally on 2026-09-29. [Installation and verification](INSTALL-2.0.9.md) records the source commit, notarization, installer checksum, tests and rollback. Public downloads remain at 2.0.4.

## Changes

- Cleaner document lists and settings, clearer actions and income figures, with the original orange accent and cream background.
- Historical payment review retains valid matches when withholding-certificate details change; unfinished edits can be recovered.
- Correct eligible old tax-invoice titles by issuing ordinary receipts after review and backup. New receipts retain the payment details and reference the originals, without adding income.
- English address fields match other inputs; corrected receipts print cleanly on A4.

Universal macOS 12+ installer, signed and notarized. New VAT invoices, e-Tax XML and cloud sync remain paused. No public deployment, Windows build or App Store submission.
