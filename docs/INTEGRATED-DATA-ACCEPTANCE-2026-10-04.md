## Account and purchase integration

The **actual coordinator route**, not only a proposal service, now supports exclusive `{receipt}` (legacy MAS) or `{signedTransaction}` (iOS StoreKit 2). The StoreKit 2 path uses Apple's official server library with pinned public root, online verification, exact bundle/product/non-consumable/environment checks and a fresh, matching current transaction from Apple before granting. Current refund, expiry, identity mismatch or unknown verification states fail closed. The SDK loads inside a request because its dependency uses randomness at import; the API transport retains official signing/validation while bounding URL, redirects, size and deadline. The underlying official OCSP operation has its own transport behavior; a 15-second caller deadline grants nothing on timeout.

Both Apple paths use one purchase-hash helper and the same account quota. Grants retain verified provenance and explicit expiry: StoreKit 2 one hour; legacy MAS 24 hours. Cached access can remain until that TTL after a refund unless a configured purchase revocation denies it sooner. **No instant refund notification/webhook claim is made.** A new grant always checks current proof. Claims precede grants and are idempotent per verified account; a storage failure returns a retryable grant error rather than attempting an unsafe cross-object quota rollback.

Verified Google audience/authorized-party pairs map to the same verified `sub`, never email, local flags, request-body account or unverified JWT claims. An explicit `GOOGLE_CLIENTS` map is authoritative for an audience and may deliberately override legacy self-pairing. Direct signed Pro grants bind to the verified Google account, retain only purchase/public-key hashes and expiry, and authorize that same account on iOS without exposing a license-entry UI. Public-key rotation, expiry, configured revocation and unrelated subjects deny access. Apple proof failures do not erase an independent valid direct grant.

Mobile first save initializes only an absent valid unbound profile; damaged storage is still blocked.
