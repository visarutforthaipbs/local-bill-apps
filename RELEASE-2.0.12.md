# BillNgai 2.0.12 — Google Drive sync for Pro

Released 2026-09-30. [Installation and verification](INSTALL-2.0.12.md). Includes 2.0.10–2.0.11.

- **Google Drive sync (Pro):** the same data on several Macs, stored in your own Google Drive. Drafts work offline; issuing a document needs internet so numbers never repeat.
- **Safe with two Macs:** if both change the same record, both versions are kept for you to choose; a payment and its receipt are reviewed together; a lost connection never duplicates a document or income.
- **Stop syncing any time:** local data stays and a backup is made first. A Mac with existing data can join by using the Drive copy (backed up first, never merged).
- **Plain messages** for no internet, missing Drive permission and Pro licence limits (up to 3 Google accounts per Pro key).
- Privacy policy updated: the sync service stores only IDs, fingerprints and document numbers — never document content, names or amounts.

Universal macOS 12+ installer, signed and notarized. New VAT invoices and e-Tax XML remain paused.
